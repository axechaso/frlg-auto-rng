# SID 练级反查：独立有限测试

本包不是应用安装包，不需要部署AI。请用 EasyCon 1.6.4a 打开相应目录的 `main.ecs`，或在自动工具的高级模式 → 脚本测试页直接选择它。`ImgLabel` 必须和脚本在同一目录，别把这些标签覆盖到正式母本。

包内两个入口：**美版-自己战斗**、**美版-学习装置**。每个入口都已配好经验方式；这不是让你手动切换原版 V3.9 主脚本。此次只测试英文ROM，日版暂不接入。

## 先测识图，确认后再测一场战斗

1. 游戏文字速度设为 FAST，关闭战斗动画。用1920×1080采集，游戏画面位置/缩放和原标签一致。
2. 自己战斗：队伍只放待反查的闪光宝可梦，放第1位，不携带学习装置。
3. 学习装置：队伍只放两只。第1位为战斗用的高等级宝可梦；第2位是待反查的闪光宝可梦，携带学习装置。两只都不能濒死，第1位不能100级；不能有第二个学习装置，战斗中不能换人。
4. 战斗者第1格放有足够PP、能够击倒当地敌人的伤害技能，保持健康。第一轮建议选1号道路，只测波波/小拉达。人物站在左右两格都可走动的草地，别在水边、台阶、墙边或训练家视线内；不用自行冲浪。
5. 打开主菜单，选“宝可梦”，进入待测宝可梦的摘要，停在显示性格的第一页。脚本从这里启动，不从NS主页、战斗中或能力页启动。原主菜单选中项必须保持“宝可梦”。
6. 在脚本顶部填写TID、待测全国图鉴编号、初始等级、原取得来源与六项已知努力值，以及倍率。野生来源地点填写TenLines名称，如`Route 1`。不清楚旧EV就不能假设为0；未知EV不能反查出可信IV。
7. 把`$训练准备确认`改为1，先保留`$训练只测试识图 = 1`运行。日志应有完整的`SIDTRAIN|BEGIN`和`SIDTRAIN|OBS`，并显示六项能力。核对是否与面板一致；初始识图正确后，重新开一份日志，把只测试识图改为0。默认最多战斗1场，可改为1–10。

没有升级时，这一场只增加EV，不输出新的能力观测。想测到升级，先把待测宝可梦练到接近升级、重新核对初始EV，或者在核对单场流程后小幅增加战斗上限。测试需要你在旁观察，不建议第一轮挂机。

## 脚本具体做什么

- 初始性格、实际等级和六项能力连续两次一致，且能力处于该物种/性格/等级/EV的合法范围，才登记初始样本。
- 左右短步遇敌；只接受17种已登记敌人中唯一最高分且连续两次一致的结果。当前支持绿毛虫、独角虫、波波、小拉达、烈雀、阿柏蛇、尼多兰、尼多朗、胖丁、走路草、地鼠、三地鼠、喵喵、火暴猴、卡蒂狗、凯西、鬼斯。未知/含糊敌人保留现场停止，不猜EV。支持物种的闪光标签命中时不攻击。
- 战斗最多8回合，选择第1格技能。战斗菜单/绿色血量未确认、未进入招式选择或空PP标签疑似命中就停止，不走医院、不用药、不切换队员。原包“技能池”图片实际上是红色`0/`，这里只用于检测空PP，不能当作“有PP”的证明。
- 自己战斗确认1条经验消息；学习装置固定两只队伍确认2条消息。只有经验标签退出低分状态后再出现才计下一条，不把同一条持续显示的文字重复计数。超过预期、缺少消息或无法确认重新打开游戏内菜单，都不提交击倒。
- 接收资格依赖你按上述要求准备队伍/道具。**当前没有自动读取持有道具来验证学习装置**，不能将“第二条经验消息”适用于任意队伍布局。这个限定测试先验收节拍，正式接入再扩展队伍规则。
- 确认结算后按物种真实EV产出增加一次，支持曾感染病毒、强制锻炼器，以及每项255/合计510上限。学习装置分享经验也获得完整EV；它与强制锻炼器不能同时持有。
- 重新打开待测摘要，读取实际等级。如果升级了，切到能力页读取并输出新能力和当前EV快照；否则只记EV，不切能力页。为验证等级读取，有限测试每场都看一次摘要，正式流程可再优化为仅升级时打开。
- 学习招式或进化消息出现时停止，让你手动处理。不会替换技能或默许进化。
- 无论成功、停止还是出错，都不发HOME、不关闭/重启游戏、不自动保存。正常结束停在待测性格页。

## 标签、日志及这次测试的边界

每个入口使用独立`TRAIN_`标签清单，来源及SHA-256在`manifest.json`。参考包只贡献必要战斗/经验标签，旧脚本的选择阶段计数、无限等待和医院路线没有照搬。正式共同母本1155个标签完全不变。

性格、等级与六项能力使用现有美版标签，图片、搜索方法及范围均保留，只改成独立的`TRAIN_`名称。每项都比较所有候选，选择唯一最高分，并要求与次高分至少相差3分；不会取第一个过阈值的值。识图失败请反馈日志及性格/能力页截图，不要降低阈值让错误数字过关。当前数字模板按1–99级读取；到100级或触发进化/学习招式时结束这次测试，不继续采集。

完整保存一次运行的日志，别只截最后几行。反馈请注明入口、图鉴、等级、初始六项EV、道具/病毒、每条经验文字属于哪只，以及脚本停止画面。测试结束后手动保存或重启由你决定；未保存而重启后，本次EV账本不能续用。

这些入口只生产观测日志，**不会自动宣告SID成功**。源码工作区可回放：

```powershell
.\.venv\Scripts\python.exe run_sid_reverse.py "本次完整日志.log" --game fr_nx
```

叶绿使用`lg_nx`。每次运行单独保存日志；需要合并时，为每次运行设置不同会话名并重新核对起始EV。只有符合顺序账本的初始和升级样本才参与反查。

当前仅做离线生成、1.6.4a绑定编译/格式和协议检查，没有连接Switch实测。请先回传只读结果，再测试单场战斗，不把离线通过当成实机通过。
