EasyCon VPad image resources
============================

The nine JoyCon*.png files in this directory are copied without modification
from EasyCon's VPad resources, via XiaoyuBook/auto-bdsp-rng commit
65a32d8cd6912a860966357c2fb37d990650524f:

src/auto_bdsp_rng/ui/vpad_assets/

The reference repository records their original EasyCon location as:

third_party/EasyCon/src/EasyCon2.Avalonia.Core/VPad/Resources/

EasyCon licenses these resources under GNU GPL-3.0. The complete license text
is included beside them as LICENSE-EasyCon-GPL-3.0.txt. The surrounding FRLG
overlay integration is maintained in this repository's manual_tools.py.
