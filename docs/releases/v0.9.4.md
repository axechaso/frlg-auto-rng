# FRLG Auto RNG 0.9.4 PySide6版

同步 2026-09-25 的 TID → 御三家连续流程修正版，内部版本码为 `2026092501`。

- TID 关闭阶段识别已经在 HOME 且游戏未运行的状态，连续确认后直接进入后续流程，不再无意义地递增关闭延迟。

- 同步 TID 连续流程的测试与文档，覆盖英文、日文、HOME 已关闭和球前存档分支。
