# FRLG Auto RNG 0.9 PySide6版

这是首次以 PySide6 作为正式界面的绿色版发布。界面、运行流程和后续打包将继续以 PySide6 为主；旧 Tk 界面不再随发布包提供。

## 主要更新

- 全面迁移到 PySide6：统一侧栏、卡片式表单、运行日志、共通设置、存档管理与结果摘要。
- 接入 SID 查找、TID 乱数、TID 实测表、野生 / 静态、孵蛋、高级脚本测试及 Seed 表更新。
- 串口与采集卡支持自动检测和下拉选择，采集卡同时显示设备名称。
- 增加监视窗口、虚拟手柄浮窗、键位设置和按设备保存的标签覆盖管理。
- TID/SID 到御三家连续流程支持固定延迟自动回填、进度续跑、实际身份衔接和 SID ADV 重试。
- SID ADV 重试优先检查相同奇偶：`0、+2、-2、+4、-4…`，用完后再检查异奇偶；确认御三家闪光后自动保存成功修正。
- 2.0 脚本同步御三家可信维度门控、严格跨轮候选筛选，并仅在 Seed 与 ADV 同轮精确命中时进入帧保持。
- 英文 TID 取名翻页增加 50 ms 等待，降低 SELECT 切页后首个方向键被吞导致名称错位的概率。
- 启动时显示开源致谢、功能简介和赞助公告，可勾选“下次启动不再显示”。
- 程序更新、Seed 表更新和 GitHub 下载继续使用 Windows 系统证书库，不关闭 TLS 验证。

## 升级方式

- `0.2.2` 用户可在旧版中点击“检查程序更新”，直接升级到 `0.9` PySide6 版。
- 更新器只替换绿色版程序目录，不覆盖 `%LOCALAPPDATA%\FRLG-Auto-RNG` 中的存档配置、日志、TID/SID 进度、实测表、Seed 表、设备标签覆盖和公告显示选择。
- 也可以下载 `FRLG-Auto-RNG-0.9-windows-x64.zip`，完整解压后运行 `FRLG-Auto-RNG.exe`。
- 绿色版已经包含 Python、PySide6、EasyCon 兼容运行环境和更新器，用户无需另行安装 Python。

## 使用边界

- 正式支持的伊机控版本仍为 EasyCon `1.6.4-a+9c86137`；本版不把 1.70 或 1.6.3 声明为正式可用版本。
- 自动化测试、脚本格式检查和离屏界面测试不能代替 Switch 实机命中验证。首次运行或更换采集设备后，请先核对游戏位置、存档、单片机、采集卡和标签匹配情况。
- 孵蛋与日版御三家等尚未完成长期实机验收的流程，界面仍会保留相应提示。
- 高级脚本测试拥有完整手柄控制权限，只应运行已经人工检查过的 ECS。
