# FRLG Auto RNG 0.9.1 PySide6版

修复 0.9 绿色版点击“开始运行”后提示 `unrecognized arguments: -u ...py`、所有脚本无法启动的问题。SID 查找、SID 遍历、TID/御三家连续流程、野生/静态、孵蛋及高级脚本测试统一使用打包版后台入口；用户无需安装 Python。

- 后台输出明确使用 UTF-8 并及时刷新，修复打包版日志中文字乱码及延迟显示。
- 构建增加真实 EXE 的四类后台入口、日志管道、日志文件、退出码和停止文件检查。
- 包含 0.9 发布后的界面更新：反查窗口分区设置、孵蛋双亲相性中英日文显示和亲本类型完善。

完整解压 `FRLG-Auto-RNG-0.9.1-windows-x64.zip` 后运行 `FRLG-Auto-RNG.exe`。现有存档资料、TID 实测表与进度继续使用 `%LOCALAPPDATA%\FRLG-Auto-RNG`，不需要重新填写。更新清单沿用现有整包协议，公开发布后旧版可通过“检查程序更新”获取。

正式运行时仍为 EasyCon `1.6.4-a+9c86137`。本次后台启动验证使用无硬件测试进程，不操作游戏。
