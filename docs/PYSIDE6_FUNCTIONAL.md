# PySide6 野生 / 静态功能版

2026-09-06：按用户选择，优先接入野生 / 静态。界面沿用已经确认的双栏布局、顶部快捷开关、紧凑存档与设备摘要；业务调用放在 `pyside_app/`，不修改正式 Tk 入口、乱数算法或源 ECS。

## 启动与操作

在仓库根目录双击 `启动-PySide6功能版.bat`，或运行：

```powershell
.\.venv\Scripts\python.exe run_pyside6_gui.py
```

首次需要安装项目依赖及可选 Qt 依赖：`requirements-auto.txt`、`requirements-pyside-preview.txt`。这是源码入口；发布 EXE 和正式 Tk 启动方式保持原样。

1. 点击右上角存档信息，选择已有存档，或手动填写版本、语言、TID / SID；在主页面选择主机。
2. 在“共通设置”核对 2.0 脚本包和 `ezcon.exe`，通过“运行准备 → 重新检测”选择串口、采集卡。
3. 选择野生 / 静态、遭遇方式、地点和宝可梦，填写 IV、闪光等筛选及消耗帧范围。指定模式需要明确选择 Seed 模式。
4. 点击“搜索并生成方案”。方案卡显示真实结果；详情中列出工程路径、路线要求、警告及预检错误。
5. 预检通过且设备就绪后，可点击“开始运行”。程序重新检查设备与生成文件；确认实际游戏设置和位置后启动。运行日志自动打开，“停止 EasyCon”始终直接可见。

更改条件、脚本路径或设备会使旧方案失效。搜索期间可以修改条件，但旧结果不会被接纳；运行期间锁定相关输入。关闭运行窗口会请求停止并等待本次进程结束。

## 数据与代码边界

- 现有存档、实测数据库、预校准和标签覆盖位于 `%LOCALAPPDATA%\FRLG-Auto-RNG`。
- Qt 自己的脚本包 / exe 路径保存在同目录 `pyside6_settings.json`。其余本次筛选条件目前只保留在窗口内。
- 每次生成使用独立 `runtime/pyside6/wild-<id>/`，保存搜索结果、工程清单、ECS 副本与独立运行日志，不覆盖正式 Tk 工程或上一次结果。
- `--data-dir <目录>` 可隔离测试用资料与生成目录。`--screenshot <PNG>` 实际显示窗口后截图，自动跳过设备检测，不执行脚本。
- `pyside_preview.py` / `启动-PySide6界面预览.bat` 仍是纯内存预览，不导入业务模块；本文件描述的接入只属于 `run_pyside6_gui.py`。
