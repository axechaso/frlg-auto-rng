# 界面文案与术语

本文件记录主界面当前使用的稳定文案和统一写法。修改 `run_auto_rng_gui.py` 的可见文本时应同步检查本表，避免脚本版本升级后仍显示旧名称。

## 主界面

- 窗口标题：`火红/叶绿全自动乱数 {版本号}`
- 正式页签顺序：`SID 查找`、`TID 乱数`、`TID 实测表`、`野生 / 静态`、`孵蛋`
- 条件显示的高级页签：`脚本测试（高级）`
- 固定末页：`运行日志`

## PySide6 界面初版

- 设计目标：让人容易操作，文案简洁直白。功能映射用于核对缺项，不复制 Tk 的密集排版；常用输入直接显示，少用参数按需展开，关键状态集中呈现。
- 窗口标题：`火红 / 叶绿全自动乱数 · PySide6 界面初版`
- 侧栏顺序：`SID 查找`、`TID 乱数`、`TID 实测表`、`野生 / 静态`、`孵蛋`；开启高级模式后显示 `脚本测试（高级）`，`运行日志`始终在末尾。默认打开 SID 页。
- 顶部状态：`存档信息`、`当前设备`
- 存档手动输入：`游戏版本`（`火红` / `叶绿`）、`ROM 语言 / 地区`（`英文（美版）` / `日文（日版）`）、`当前 TID`、`当前 SID`。
- 常驻预览标识：`界面预览`，悬停说明 `仅预览布局，搜索、设备与运行服务尚未接入。`；底栏仍显示 `界面预览 · 尚未生成方案`。
- 顶部常用项位于 `高级模式` 左侧：`低分自适应`（HOME_BUFFER 稳定低分自适应）、`命中后更新预校准`、`Seed 校准`、`Seed 启动`。Seed 方案简短名称配合完整悬停说明；`脚本输出日志` 留在共通设置。
- 该入口是独立视觉原型，不是正式 GUI 文案已经全部迁移的声明；接入后端前仍以 Tk 主入口和本文件其余正式文案为准。
- 公共入口：顶部摘要可点击打开 `存档信息` / `共通设置`，右侧提供 `查看方案与预检详情`，窄屏及实测表通过 `方案与设备` 打开摘要。尚未接入的操作禁用，状态使用 `尚未检测`、`尚未校验`、`暂无方案`，不使用示例“已就绪”或“已检测”。完整功能归属见 `PYSIDE6_PAGE_MAP.md`。
- 公共区域：`存档信息`、`当前设备`、按输入模式命名的方案卡、`运行准备`。底栏直接显示生成、`取消搜索`、`开始运行`、`停止 EasyCon`，不隐藏取消与停止操作；窄屏隐藏底栏说明文字以保留全部按钮。
- 公共脚本日志：`脚本输出日志`，选项为 `精简日志`、`完整调试日志`
- 高级反查：`奇偶调整`、`扩窗层数`、`Seed 容差（±）`、`消耗帧半宽（±）`
- 高级模式旁的 `高级设置…` 打开脚本入口和反查参数，可直接定位 `TID 闪 PID`、`SID 遍历起点`、`脚本测试`。
- 仅大分区标题旁保留 `?`，支持悬停或点击查看说明；小字段不放问号，标签、输入和复选框悬停时显示解释。说明映射见 `PYSIDE6_HELP_MAP.md`。
- TID 穷举补充：`穷举额外目标 TID`、`接近目标区间后自动转乱数`、`接近距离（±）`、`确认次数`、`转乱数后 OP / F1 / F2 半径`。这些选项不属于高级模式专属；帧数单位按当前 Tk 写为 RNG advance，固定延迟使用 ms。

## 各页主要分区

### SID 查找

1. `SID 查找条件`
2. `队伍闪光宝可梦信息`

`SID 查找脚本` 放在 `共通设置`。

### TID 乱数

1. `TID / SID 基本条件`
2. `乱数中心 / 穷举范围`
3. `游戏设置与固定延迟`
4. `御三家连续乱数`
5. `穷举判定与高级范围`
6. `参数保存与穷举续跑`

`TID 1.3.7 脚本包` 放在 `共通设置`，保留 TID 独立路径。

### 野生 / 静态

1. `乱数条件`
2. `筛选与最大 Advance`

### 孵蛋

1. `孵蛋运行条件`
2. `孵蛋目标`

启动确认统一写为 `我已确认孵蛋前置条件，允许启动流程`。尚未完成整轮实机验收的说明保留在相邻帮助中，不再把“测试”“实验性”“正式 WAIT”堆在页签和常驻复选框里。

## 统一术语

- 当前普通/孵蛋入口统一称为 `2.0 自动乱数脚本`；目录输入称为 `2.0 自动乱数脚本包`。
- `1.1.8` 仅用于实际历史目录名、兼容资产名或历史文档，不再作为当前界面版本名称。
- EasyCon 固定写为 `EasyCon 1.6.4-a`；不在界面中混用 `1.6.4a`、`164a` 或“伊机控 170”。
- 英文缩写与中文之间留空格，例如 `Seed 模式`、`Seed 校准`、`SID 遍历`、`TID 参数`、`Switch 机型`。
- 范围使用连接号 `–`，例如 `0–31`、`0–65535`；单位前留空格，例如 `1200 ms`、`100 ADV`。
- 脚本内部变量、ECS 函数名、日志协议标记和真实文件夹名保持原样，不为界面排版改名。
- 第三世代 `SuperRod` 显示为 `厉害钓竿`；`超级钓竿`仅保留为旧输入兼容名。

## 按钮与状态

- 主操作：`搜索并生成方案`、`取消搜索`、`开始运行`、`停止 EasyCon`
- 设备：`检测端口/采集卡`、`虚拟手柄`、`监视窗口`
  - `虚拟手柄`：打开键盘控制窗口，并自动显示采用 EasyCon 原版 VPad 图片的 100×100 置顶状态浮窗；绿色表示当前按键，左键唤出控制窗口，右键拖动，中键隐藏。
- 更新：`检查/更新 Seed 表`、`检查程序更新`
- 孵蛋配置：`保存亲本配置`、`载入亲本配置`、`保存全部配置`、`载入全部配置`
- TID 工具：`6V 闪 SID`、`先检测固定延迟，完成后自动运行计划`

动态状态先说明结果，再给文件或下一步；硬错误、运行状态和危险确认保持常驻，解释性长文放入悬浮帮助。

## 悬浮帮助边界

- `高级模式`必须说明它同时开放脚本测试、Seed、扩窗和奇偶设置，并且只放宽指纹不一致，不放宽缺文件、语法和参数错误。
- `脚本输出日志`必须与脚本测试页的 `输出 EasyCon 详细日志`区分：前者写入生成的 2.0 ECS 参数，后者控制直接运行器输出。
- `反查扩窗与奇偶调整`必须说明各层是相对目标中心的绝对半宽、扩大窗口会增加耗时、0 层关闭，并明确孵蛋固定菜单奇偶。
- 页面中尚未完成的实机验收边界保留常驻或相邻帮助，不能因文案精简改成已验证结论。
