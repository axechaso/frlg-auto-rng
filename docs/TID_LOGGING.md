# TID 每轮日志

按用户提供的 `【TID+SID乱数&穷举】英文版-火红叶绿1.3.7.txt` 恢复“目标信息 / TID数据 / 当前搜索进度”结构。英文和日文通过同一个日志生成器调整，只作用于工具从新版 164a 模板生成的副本。

- 每轮显示目标列表或当前锁定目标、SID ADV、劲敌取名、语言、机型、五位 TID、同参数命中次数和观察次数、OP/F1/F2、名称、SELECT、HOME_BUFFER、OP修正及各项按键设置。
- 穷举显示当前阶段、偏移与上限；乱数显示中心、当前偏移、实际负向/正向范围和当前壳层。自动切换前先打印该轮观测，再打印切换事件。
- “发现候选”与“通过去噪确认”分别输出。普通 TID 即使在窗口内重复，也只保留观测；整段回填参数只在目标确认成功时输出一次。
- 窗口决策的距离标为“窗口最近环形差值”，与本轮观测的差值分开。
- 日志窗口隐藏完整的 V1/V2/V3 机器检查点；原始运行日志、TID记录及进度恢复仍收到原始内容。错误、未知版本和不完整记录保留显示。

[日志示例](examples/tid-log-example.txt) 由生成脚本的打印函数在合成状态下执行得到，用于查看格式，不是 Switch 实机记录。回归测试另行核对打印前后搜索变量、SID ADV、TID 记录和进度传递。

已有生成目录和已打包 EXE 不会随源码改变。使用更新后的源码工具重新生成 TID 脚本后生效。
