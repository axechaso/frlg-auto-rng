# TID 多目标与自动转乱数

适用于正式 Tk 工具使用的新版 `NS火叶TID-SID到御三家球前存档-测试.ecs` 模板，运行时仍为 EasyCon `1.6.4-a+9c86137`。扩展写入工具生成的副本；下载目录原脚本和御三家球前路线不改写。更新源码后须重启工具、重新生成方案；旧 EXE 和旧生成工程不会自动获得这些功能。

## 填写

TID 页第 2 区新增：

- **穷举额外目标 TID**：主目标始终参与，额外目标以逗号或空格分隔，最多 31 个。例如主目标 `00000`，额外填写 `33333, 65535`。允许前导零，数值限定为 0–65535，重复值只搜索一次。手动乱数模式仍使用主目标。
- **接近目标区间后自动转乱数**：按需勾选，默认关闭以保留旧配置行为。
- **接近距离 / 次数**：默认环形距离 `100`、同参数窗口内 `3` 次，次数不能超过去噪窗口。TID 65529 距离 00000 为 7。
- **自动切换后半径**：OP / F1 / F2 默认 `20 / 20 / 10`，与手动乱数半径分别保存。

“取得任意 TID 后继续”开启时，仍按任意 TID 流程衔接，不启用多目标或自动切换。

## 何时切换

完整且合法的 TID 才进入观察窗口。每个明确填写的目标分别统计，允许同一参数产生多个不同的附近 TID；不同目标的次数不能相加。优先选择接近次数最多的目标，平票时比较这些接近样本的距离总和，仍平票时按填写顺序。最后一次偏远结果不会抹掉前面已有的证据。

首次接近只作为线索，继续观察当前参数；穷举和乱数都不会因另一个普通 TID 重复达到原去噪次数而提前放弃有线索的点。达到接近次数后切换，窗口满而未达标则继续穷举。穷举推进按整个窗口的F1近区次数、F2候选区次数、最短距离依次选候选，再沿原分层规则推进。更换参数、OP 启动恢复或续跑时重新观察，不跨参数积累接近次数。原有特殊号码筛选继续用于穷举，但自动切换只由明确填写的目标触发。

切换采用当轮实际 OP/F1/F2 总帧作为中心，锁定对应目标，清空观察窗口，并从中心开始原有的步长 2 壳层搜索。目标距离不当成 OP/F1/F2 的线性补偿。切换后关闭特殊号码筛选，只接受锁定目标；指定 SID 时按该目标 TID 重新计算 SID ADV。穷举阶段为补齐时序而增加的等待会转入乱数计算等待，保留原名称、SELECT、HOME_BUFFER、OP 修正与设备设置。

切换后的记录须重新满足精确 TID 去噪条件，才会停止或衔接后续流程。不能把“接近目标”当成实际 TID 命中或 SID 验证成功。

自动切换后的局部范围完整搜索一遍仍未命中，就恢复切换前的穷举位置、固定延迟补齐、主目标及特殊号码筛选，并按该窗口的候选结果推进下一点。指定SID的临时劲敌取名/F3补偿也会撤回。手动乱数模式仍按设定范围循环；自动局部搜索不会无限停留在同一区域。

最近16个完成区域随检查点保存。同一目标在已完成区域内部且帧奇偶相同的参数点，继续穷举观察而不再次启动局部搜索；不同目标不共用这个限制。缓存满后替换最旧记录。OP修正不同的记录不互相抑制；如果局部搜索中途发生OP自动修正，本轮不登记为完整区域，防止将混合时序误当成完整覆盖。

## 半径自动修正

两个模式的负半径归零，奇数半径按原搜索步长 2 向下取偶数。乱数半径越过可执行最小帧时，只裁剪负向不可执行的一侧，保留正向范围。例如中心高于下限4帧、要求±20时，实际搜索−4到+20。若中心自身低于可执行下限，则先提升到下限，负向范围为0，正向仍搜索到+20。穷举起点仍沿用原脚本自动提升到可执行下限的逻辑。日志和进度显示实际负向/正向范围；不会因这些范围问题进入原来的等待停机循环。

## 刷新进度与续跑

第 7 区“刷新进度”和“继续同参数的上次搜索进度”支持穷举及非零半径乱数，包括从穷举自动切换的乱数。手动乱数半径全为 0 时重复同一点，无需保存搜索位置。

检查点保存当前模式、是否自动切换、锁定目标、中心、正负向范围、壳层、三个搜索索引、累计轮数、穷举返回位置、完成区域缓存及原 OP 恢复修正/重启等待。恢复时重试停止时的当前点，清空去噪和区域证据，不跳过未完成观察。自动切换后会恢复到乱数模式，局部搜完后仍能回到原穷举位置。

指定 SID 的连续御三家流程按 SID ADV 修正分别保存检查点，“刷新进度”显示最近使用的修正。中断后优先恢复最近未完成的 TID 搜索尝试；不恢复御三家或保存动作的中途画面。

进度按游戏、设备、完整请求、模板指纹和搜索版本隔离。本次搜索版本为 3，旧检查点保留在原位置，不静默迁移到新版。参数仍存于用户目录的 `tid_settings.json`，进度仍位于 `tid_progress/`。

## 验证边界

定向测试回放实际生成的 ECS 函数，覆盖环形距离、多目标分票、窗口重置、切换前后毫秒时序、半径修正及壳层续跑。另使用真实 1.6.4-a 格式检查及编译绑定检查。尚未运行 Switch 实机，不能据此推断命中率提高。
