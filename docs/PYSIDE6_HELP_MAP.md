## 顶部功能与多模式说明（2026-10-05）

- 当前共 13 组、79 步。新增顶部七步：区分 Seed 模式/启动/校准 → 低分自适应 → 校准 0/1/2 → 启动 0/1 → 更新预校准 → 标签故障保护 → 高级模式。旧步骤 ID 与版本 1 保留，顶部使用独立 `controls` 阅读进度。
- 每个多模式选项说明“每种做什么、区别在哪里、什么时候选、哪些流程不适用”；不把模式编号当成质量等级，不承诺某种校准或时间轴入口命中率更高。
- HOME_BUFFER 自适应默认关闭：同一状态连续三次相同、唯一最高且至少 90 分，才能接受较低阈值；不影响性格/等级/能力值识别，不会自动重做标签。
- Seed 校准：0 为最近 12 轮绝对落点众数，1 为锁定细调，2 在命中保持结束后接续 ±1 方向记录。野生/静态默认 0、孵蛋默认且独有 2；连续御三家实际固定 0，TID 建档/SID 采集不使用此选择。
- Seed 启动：0 使用 HOME_BUFFER 校准，1 使用固定 HOME 等待；启动方案分别保存预校准，不能混用，也不替换 TID/SID 自己的启动流程。目标页的 Seed 模式是游戏设置组合，另解释 0–9 分组及日版御三家专用模式 10。
- TID 补充目标/实际 SID、固定延迟检测/手动编辑、穷举/乱数/接近目标自动切换、去噪开关、6V SID 与游戏设置区别；野生补充道具/普通刷闪/SID 遍历、自动/指定目标、抓捕/录像/非目标停止；孵蛋补充固定/自动模式、相性 20/50/70 和两种准备入口。
- 共通与高级窗口补充精简/调试日志、自动/手动更新源、正式/时间轴/自选 ECS、菜单/F1-F2 奇偶调整与三套反查范围；脚本测试明确兼容/原始后端差别。同步修正悬浮帮助中“指定 Seed 必须手选”及“预校准默认关闭”的旧说明。
- SID 遍历教程即使开关关闭也可阅读，避免用户必须先开启业务功能才能了解用途。顶部状态读取真实开关/选项，并提示 TID/SID 的适用边界；阅读不会自动填写、连接、开启高级模式或运行脚本。
- 小设置窗口优先使用控件上下或左右的空白区，必要时缩小可滚动提示卡，不遮住正在介绍的字段；主窗口仍为停止栏保留空间。
