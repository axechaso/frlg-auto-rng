# PySide6 页面说明与分步引导

更新：2026-10-03。以正式 `CompleteWindow` 为准。页面业务服务已接入；旧预览时期“日志 / 搜索未接入”的说明不再适用。

## 入口与阅读进度

各页标题右侧“本页引导”提供开始 / 继续、重新开始和引导目录。首次进入显示可关闭的轻量提示，用户主动点击后打开教程。支持上一步、下一步、暂时收起、本页不再提示；原字段悬浮说明和卡片问号继续使用 `assets/pyside_preview/help_text.py`。

引导保存到用户目录 `guide_state.json`，采用 `frlg-page-guides/v1`、版本号及每页稳定步骤 ID。重启继续原步；步骤消失时回到可用首步并提示。损坏文件保留，不自动覆盖。阅读进度不构成设备连接、现场准备或业务完成证据。

## 八个侧栏页

| 页面 | 引导顺序 / 主要锚点 | 必须说明的边界 |
| --- | --- | --- |
| SID 查找 | 存档 → SID 条件 → 队伍 → 糖果确认 → 设备 → 搜索 / 运行 | 物种、等级、来源、相遇地和 EV 分槽输入；实际读取需要设备和游戏准备 |
| TID 乱数 | 基础身份 → 范围 → 固定延迟 → 连续流程 → 续跑状态 → 运行 | advance 与 WAIT 毫秒不同；切换、去噪和连续御三家按实际勾选状态生效 |
| TID 实测表 | 列表 → 条件 → 导出 → 日志核对 | 实测记录不是命中率承诺，导出范围以当前条件为准 |
| 野生 / 定点 | 存档 → 方法 / 类别 → Seed / ADV → 条件性 SID 遍历 → 搜索 → 方案 → 运行 | Gift 遍历未放行；钓鱼、狩猎区、领取等准备以真实分支为准 |
| 孵蛋 | 存档 → Seed / Held / Pickup → 亲本 → 准备入口 → 搜索 → 方案 / 运行 | 254 步基础档、领取路线和前置确认以当前入口说明为准 |
| 脚本测试 | 脚本 → 后端 → 危险确认 → 方案 → 运行 | 隐藏时只说明入口，不自行开启高级模式 |
| 运行日志 | 当前输出 → 脚本操作 → 故障卡 → 设备覆盖 → 停止 | 手柄和日志卡共用只读状态；缺状态不推测按键，旧故障不自动弹窗 |
| 历史日志 | 后台列表 → 流程筛选 → 搜索 → 尾部预览 → 打开原文件 | 默认 256 KiB / 3,000 行，更多最多 1 MiB；删除文件不自动改看另一项 |

`assets/pyside_preview/guide_steps.py` 定义正文、稳定步骤、真实锚点和只读检查；`pyside_app/page_guides.py` 负责状态与入口，`guide_overlay.py` 绘制聚光层和原生提示卡。没有复制上游 BDSP 代码或资产。

## 设置与相关窗口

| 入口 | 覆盖内容 |
| --- | --- |
| 存档信息 / 创建存档 / 管理 | 身份字段、语言 / 主机、神秘礼物、保存和复制；管理窗口使用自身列表和字段 |

设置窗口由用户点击原入口打开后才展示引导。教程不会保存业务参数、生成方案、启动采集、发按键或运行脚本。完成检查读取真实设备、方案、现场状态；控件不可见或分支不适用时明确说明。

## 布局与运行期间行为

聚光区域来自实际 QWidget 几何，滚动、缩放、窗口和 DPI 改变时重新定位。提示卡使用周围空位，全宽表格使用侧栏空间，避免遮挡被解释区域。非模态提示可收起，Esc 只关闭教程；运行参数按原逻辑冻结，停止按钮保持可见和可操作。

本轮离屏布局检查：1,280×800 / 1,920×1,080，各 100% / 150% / 200% DPI，共 252 步，涵盖八页和存档 / 共通 / 高级窗口。加载 Windows 实际微软雅黑 / Segoe UI 并检查截图。标签八步锚点和事务流程另由离线测试覆盖。详见[实施复验报告](acceptance/2026-10-03-six-feature-implementation.md)，不代表 Switch 实机验收。

## 原有帮助和高级模式

- Seed、正式 / 时间轴、自选 ECS、奇偶和反查范围沿用已有业务限制；神秘礼物存档仍强制有效方案 1。
- SID、糖果、EV、孵蛋间隔、亲本组合、TID 续跑说明与生产校验一致，不移植旧脚本未支持的模式。
- 时间单位保持实际刷新 60 Hz、RNG advance 120/s，`WAIT` 为真实毫秒。
- 原有 `help_text.py` 和 QQ 教程继续使用，本轮不恢复 Tk 界面。
