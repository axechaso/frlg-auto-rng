# 悬浮说明与高级模式核对

## 本轮发现

- 旧预览只保留少量 `setToolTip`，大部分 Tk 帮助没有迁移。
- 脚本入口、奇偶调整和三层扩窗字段已经存在，但在共通设置底部，开启高级模式后缺少直接可见的入口。

- 旧预览将 TID OP / F1 / F2 单位写为游戏画面帧，与当前 Tk 文案不符；现统一为 RNG advance，沿用脚本的 120.00144 advance/s 说明，未修改时间换算或算法。

## 2026-09-06 脚本注释转为字段说明

从正式工具当前优先使用的 `local_assets/easycon118`、`local_assets/tid_rng137` 脚本包阅读参数注释，再对照现有请求校验与生成补丁。只将用户需要的含义、单位、前置条件整理成静态提示，不在预览运行时读取或导入脚本。

| 注释来源 | 对应位置与整理内容 |
| --- | --- |
| `local_assets/easycon118/NS火叶SID反查-采集测试.ecs` 参数区 | SID 确认与糖果：先存档、逐只读档、糖果消耗不保存；六槽各自的物种、初始等级、来源、相遇地点与 EV 分开提示；页面识别与糖果阈值区分 |
| `local_assets/easycon118/NS火叶全自动一键乱数2.0.ecs` 及时间轴版参数区 | 十六进制 Seed、目标 ADV 单位、Seed 校准逐项含义、固定 HOME 启动顺序、两种帧奇偶方案 |
| 同脚本孵蛋参数区与 `local_assets/easycon118/lib/27_孵蛋测试流程.ecs` | 蛋种、同 Seed 的 Held / Pickup、至少 1800 ADV 间隔、20 / 50 / 70 相性、亲本 A / B 性别与实际 IV |
| `local_assets/tid_rng137/【TID+SID乱数&穷举】英文版-火红叶绿1.3.7.txt` 及日文版参数区 | 主角名与性别变更需重测、日文浊音拆写、Sound / Button Mode / Seed Button、旧数据的取名进入键、SELECT 次数、HOME / 关闭等待、去噪命中与窗口、候选阈值及场景 OCR |

复核边界：

- SID 以 `automation/sid_reverse118.py` 为准：糖果 0–20、识图 1–100、单项 EV 0–255 / 总和不超过 510；预览两个数值框的上下限同步校正，不增加业务校验或执行能力。
- 孵蛋以 `automation/easycon118.py` 为准：Seed 0000–FFFF、Held 大于 0、Pickup 至少晚 1800 ADV；亲本 B 可为雄或无性别，未照搬旧注释中“B 固定雄”的限制。
- TID 以 `automation/tid_rng137.py` 与 `automation/tid_search_policy.py` 为准：去噪命中数不能超过窗口；候选按同参数整窗口证据选择，号码距离不等于帧补偿。未搬入旧注释“任意一个去噪值改 1 即可关闭”的不完整建议。
- 旧 TID 脚本头的“1.60 以上”、内部调试开关、尚未支持的 Seed 模式和运行实现细节未搬入界面；正式运行时约束仍为 EasyCon 1.6.4-a+9c86137。

小字段仍无问号，标签与输入均可悬停；六槽 EV 和亲本 IV 使用各自的具体说明，避免整行重复一段笼统帮助。顶部 Seed 每个选项的说明也使用限宽富文本，保持长说明可读。页面布局、脚本与后端入口不变。

## 高级模式入口与范围

| 设置 | 开启高级模式后的位置 / 范围 | 关闭后的行为 |
| --- | --- | --- |
| Seed 校准 / 启动 | 主窗口顶部；普通校准 0 / 1，孵蛋 0 / 1 / 2；御三家实际请求始终锁定 0 | 普通 0、孵蛋 2、启动 0；输入禁用 |
| 正式 / 时间轴 / 自选 ECS | 高级模式组合控件右侧“设置”；自选仅脚本测试页提供 | 恢复正式入口 |
| 奇偶调整 | 高级设置；野生 / 静态、孵蛋、连续御三家适用，孵蛋固定菜单方案 | 设置按钮禁用；当前手动值保留但不启用 |
| 0–3 层扩窗、各层 Seed / ADV 绝对半宽 | 高级设置；范围同上，SID 查找和直接脚本测试不适用并显示原因 | 手动值保留但不启用；模板默认值仍未读取 |
| 6V 闪 PID | TID 基本条件 | 恢复 7942EF72 并禁用 |
| SID 遍历起点 | 野生页独立 SID 遍历折叠栏；仍须开启野生 SID 遍历才可编辑 | 输入保留但禁用 |
| 直接 ECS 测试页 | 侧栏高级页 | 页签隐藏；若正在该输入模式则回野生页 |
| 指纹放宽 | 悬停说明保留正式约束 | 本预览始终不执行预检；缺文件 / 语法 / 参数错误不会被描述为可忽略 |

高级设置使用一份独立窗口，关闭后输入保留；不放置跨页面跳转按钮，主界面不常驻铺开扩窗表格。SID / TID 脚本路径和日志等级仍在共通设置。
