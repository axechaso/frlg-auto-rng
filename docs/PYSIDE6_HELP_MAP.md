# 悬浮说明与高级模式核对

2026-09-05 对照当前 `run_auto_rng_gui.py` 的 `_help_marker` / `_add_tooltip` 和高级模式控制函数。初版视觉基准仍为 `7438e0e`；本表记录说明内容与入口，不表示正式服务已接入。

## 本轮发现

- 旧预览只保留少量 `setToolTip`，大部分 Tk 帮助没有迁移。
- 脚本入口、奇偶调整和三层扩窗字段已经存在，但在共通设置底部，开启高级模式后缺少直接可见的入口。
- TID 额外目标、接近目标区间自动转乱数及其参数尚未映射；它们属于穷举选项，不是高级模式专属。
- 旧预览将 TID OP / F1 / F2 单位写为游戏画面帧，与当前 Tk 文案不符；现统一为 RNG advance，沿用脚本的 120.00144 advance/s 说明，未修改时间换算或算法。

## 高级模式入口与范围

| 设置 | 开启高级模式后的位置 / 范围 | 关闭后的行为 |
| --- | --- | --- |
| Seed 校准 / 启动 | 主窗口顶部；普通校准 0 / 1，孵蛋 0 / 1 / 2；御三家实际请求始终锁定 0 | 普通 0、孵蛋 2、启动 0；输入禁用 |
| 正式 / 时间轴 / 自选 ECS | 高级模式旁的“高级设置…”；自选仅脚本测试页提供 | 恢复正式入口 |
| 奇偶调整 | 高级设置；野生 / 静态、孵蛋、连续御三家适用，孵蛋固定菜单方案 | 高级设置入口隐藏；当前手动值保留但不启用 |
| 0–3 层扩窗、各层 Seed / ADV 绝对半宽 | 高级设置；范围同上，SID 查找和直接脚本测试不适用并显示原因 | 手动值保留但不启用；模板默认值仍未读取 |
| 6V 闪 PID | TID 基本条件；高级设置可直接定位到该字段 | 恢复 7942EF72 并禁用 |
| SID 遍历起点 | 野生更多筛选；高级设置可直接定位，仍须开启野生 SID 遍历才可编辑 | 输入保留但禁用 |
| 直接 ECS 测试页 | 侧栏高级页，或高级设置中的定位按钮 | 页签隐藏；若正在该输入模式则回野生页 |
| 指纹放宽 | 悬停说明保留正式约束 | 本预览始终不执行预检；缺文件 / 语法 / 参数错误不会被描述为可忽略 |

高级设置使用一份独立窗口，关闭后输入保留；主界面不常驻铺开扩窗表格。SID / TID 脚本路径和日志等级仍在共通设置。
