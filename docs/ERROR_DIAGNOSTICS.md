# 错误弹窗与排查提示

## 用户怎么查看

PySide6 正式工具发生需要弹窗的错误时，窗口依次显示：

1. 简短说明：这次哪类操作没有完成。
2. 原始错误：保留具体字段、标签名称、文件路径或异常内容；长错误只缩短这里的显示。
3. **可能原因（需核对）**：按报错内容列出可能情况，不当成已经查明的根因。
4. **建议排查**：先确认什么，再怎样重试。

点击“查看详细信息”可展开未经删改的完整原始错误，再点击“收起详细信息”折叠。文字可选中复制。运行错误还应到“历史日志”查看完整日志，不只截取最后一行。

信息不足时明确写“当前信息不足以确定原因”，提示保留工具版本、所在页面、刚做的操作和现场截图，不编造设备故障，也不让用户先清空资料。

## 主要提示范围

| 报错类型 | 优先检查 |
| --- | --- |
| 输入或前置条件未通过 | 按原始错误点名的字段检查空值、范围、选项及准备确认；任务仍在运行时先等待或停止。 |
| 串口连接失败 | 重新检测并选择正确串口，检查其他伊机控/串口程序占用、USB连接和握手日志。一次超时不能证明单片机损坏。 |
| 采集失败、识图范围越界 | 确认设备名称、画面与占用情况；画面恢复后仍越界再核对实际分辨率与标签范围。越界不能靠降低阈值修复。 |
| 标签数量、结构或内容检查失败 | 核对当前完整包的 ImgLabel，避免旧目录、历史TID子集或不完整解压；脚本与标签必须同版本。 |
| 缺少当次标签备份 | 保留故障资料，补充该运行工程实际使用的标签；不能用其他版本的同名文件冒充现场证据。 |
| 标签验证未完成、相邻页误命中 | 确认页面并完成同图、三张新帧及可选的相邻页验证；没有通过的修改只保留为草稿。 |
| 模板字段、锚点或入口不符 | 检查当前工具与完整脚本包是否配套，记录具体缺失字段/入口。 |
| 计划失效或未通过预检 | 按当前参数、文件和设备重新生成并预检，不沿用旧工程。 |
| 路径失效、文件无法写入、磁盘空间不足 | 检查原始路径及目录权限/占用；更新替换时关闭程序目录的资源管理器窗口，保留配置和日志。 |
| 更新网络/证书/HTTP错误 | 核对时间、代理、证书链和更新源，必要时手动换源。网络超时与认证失效分开判断，不关闭证书验证。 |
| DLL组件加载失败 | 在新独立目录完整解压，避免只复制EXE或混用旧DLL；核对系统及安全软件记录。 |
| 搜索无结果、Seed表缺失或不可达 | 核对目标、身份、游戏/语言/机型、表与帧范围，按需求调整筛选；无结果不等于设备出错。 |
| HOME_BUFFER判定、页面识别或反查失败 | 对照实际页面、语言、分辨率、当轮标签分数、范围与读取数值；保留现场和完整日志再处理。 |

已有“识别故障检查与修复”窗口也显示可能原因与排查步骤，仍保留标签名、分数、阈值、阶段、截图和日志入口。缺少证据会明确说明；OR候选中的一个低分不等于坏标签，最高分也不能单独证明识别正确。

## 行为边界

- 这是**错误展示**功能，不是自动修复：不会发送手柄按键、重启游戏、上传资料、删除文件或改写用户参数。
- 不自动降低标签门槛，不关闭HTTPS验证，不改变高级模式指纹规则、更新源策略、预检或脚本校准/重试逻辑。
- 不把每一条识图重试日志当成新故障。既有阶段故障保护的开关、触发条件、取消/正常退出静默规则保留。
- 自动更新检查失败仍静默；用户主动检查发生错误时才显示排查弹窗。正常信息、成功提示和危险操作确认保持原语义。
- 仅在PySide6正式进程已经启动、进入受处理的错误入口后生效。Python或Qt在导入阶段就无法启动时，仍需通过启动器/终端查看原始错误，不宣称此弹窗能拦截启动前崩溃。

## 实现与复验

- `pyside_app/diagnostics.py`：`explain_popup_error`只分类实际弹窗错误；日志用的`explain_error`仍仅识别已核实的ROI断言及旧整数异常，防止普通重试被误标故障。具体异常优先于外层笼统提示，串口/采集错误使用同一行的设备主体与失败内容，避免“连接成功”标题和后续游戏超时被拼成连接故障。
- `pyside_app/error_dialog.py`：统一只读消息框。原始内容使用PlainText显示，短摘录与完整详细信息分开，确定和详情按钮均为中文。
- 主窗口、程序更新、存档保存、键位保存、公告偏好、标签制作与故障引导复用此入口；原失败返回、草稿保留及持久化成功/失败语义不变。
- 回归入口：`tests.test_pyside_diagnostics`、`tests.test_pyside_app_update`、`tests.test_label_repair_prompt`、`tests.test_pyside_controller`、`tests.test_label_editor_flow`、`tests.test_pyside_startup_notice`。需核对原始内容完整、分类优先级、未知错误不乱归因、详细信息展开/收起、保存失败保留草稿、自动更新与普通重试不弹窗、配置和进程状态不被提示改写。
- Windows视觉证据位于忽略目录 `.tmp/error-advice-20261007/`。离线测试与消息框截图不代表已经连接Switch完成设备故障验收。
- 2026-10-07复验：新增16项回归方法，分类样例34种；仓库全量896项通过（326.292秒），Python编译及diff空白检查通过。旧保存失败测试同步改为拦截新的统一弹窗入口，不修改生产保存策略。
