# Seed–ADV 共同紧密区

更新日期：2026-08-28。正式运行环境仍为 EasyCon 1.6.4-a+9c86137。

## 范围与依据

保留方案0、方案1原有 Seed 控制器、帧轴、停糖与游戏操作。只替换旧跨轮“连接成簇”的候选辅助，正式/时间轴入口使用同一段库代码。

用户提供的实测日志在第9轮识别到闪光，上一轮为目标Seed、ADV差1，并触发已有的5轮3票慢修正。用户报告此前方案0、未加交集的运行用了27轮。记录为一次正面样本，不据此保证新版命中率或把改进全部归因于交集。旧跨轮版本另存用于同配置对照。

## 规则

- 每轮保留实际的 `(归一SeedMS, 归一ADV, 归一Seed索引)` 配对；同Seed不同ADV不压缩成区间。
- Seed坐标为 `取MS(实际Seed索引 + 累计索引修正) + NX平台偏移`；ADV坐标为 `实际ADV + 已执行帧修正`。用实际Seed表，不能用固定毫秒乘索引。坐标不是下一轮等待时间。
- 一只宝可梦只提交吃糖细分结束后的最终候选集；同只吃糖、扩窗不增加轮数。完全相同的配对集合（无论顺序）不重复计票。
- 保存最近12个不同的完整候选集；每轮在一个共同区中最多计一票。每轮最多缓存200对，超出只禁用本次不完整证据，不裁剪原反查搜索或候选选择。
- 共同区必须同时满足 Seed **总跨度≤100ms**、ADV **总跨度≤30 advance**。均为实验默认值，不是半径。枚举二维窗口，绝不按相邻点连通性合并。
- 排序依次为覆盖轮数降序、ADV跨度升序、Seed跨度升序；相同指标按Seed下界稳定显示。算法保留真实配对，不组合不存在的两个轴。
- 至少覆盖3轮、覆盖当前有效轮数的严格多数、且同覆盖的解释不存在分离区域，才给后续候选增加二维距离分。只辅助选择，不直接把中心当成真值或改写校准参数。多个解释的包络若超任一总跨度上限，标为歧义并停止参与排序。
- 不完整数据、越界归一索引或达到计算工作量上限时明确输出诊断，不把中途结果当最终结论。原反查继续按原规则工作。

## 配置与日志

在 `lib/25_校准_投票决策.ecs` 的共同区模块全局区可调整：

```text
$共同区Seed总跨度 = 100
$共同区ADV总跨度 = 30
$共同区参与排序 = 1
$共同区输出配对 = 0
```

`参与排序=0` 保留共同区诊断，只关闭距离分；不是恢复旧串簇算法。生成器重新物化时保留这四项已填写的值。原版对照须运行保存的旧副本。

日志分别显示归一范围、中心与最大偏差、覆盖、是否存在分离解释、本轮扫描是否使用、下轮是否允许使用。首位区域不是最终真值。“Seed交集为空”不再混用原始毫秒交集与归一索引交集。

需要复盘完整候选时启用 `共同区输出配对`，输出 `COMMON_PAIR`；默认关闭以免大量打印。旧日志只有每簇包络，没有各轮所有配对，不能从中还原新版精确排序结果。

## 实现与验证入口

- `assets/easycon118_extensions/seed_common_regions.ecs`：规范实现；生成时嵌入原有25号库，不增加脚本文件数，不需要额外Python进程。
- `automation/seed_common_regions.py`：幂等升级，移除已知旧跨轮钩子；保留其他投票函数。工具物化与普通/孵蛋生成均接入。
- `tools/install_seed_common_regions.py`：默认只预览，显式 `--apply --backup <新目录>` 才同步原包，并保留两份旧入口、lib与标签。禁止覆盖已存在的备份。
- `tests/test_seed_common_regions.py`：执行实际ECS控制流，120组随机配对与逐轮穷举结果对照，以及串簇、同ADV边界、重复、容量、歧义、归一化、12轮窗口回归。
- `tools/EasyCon164aCommonRegionCheck`：使用工具现有1.6.4-a引擎做不连接硬件的编译/运行检查；支持 `--compile <完整入口>`，以及 `<规范ECS路径> --stress` 的12轮×200对容量检查。

这轮不重新打包EXE，也不改写正在运行的 `runtime/easycon118/main.ecs`。非打包版重新生成方案后生效；打包版需要另行发布。必须继续做同配置Switch实机对照，离线通过不等于命中率已经提高。

本轮验证：工具全量352项测试、原包30个检查脚本通过；原包两入口、工具缓存两入口、独立生成的普通/孵蛋两入口，共6份通过真实1.6.4-a格式和绑定检查。原生引擎12轮×200对压力序列通过，整组约8.7秒。检查记录在 `.build/common-region-validation-20260828/report.json`；未进行Switch实机操作。
